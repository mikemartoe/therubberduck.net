Official Federal Register PDFs are hosted on R2 at https://memes.therubberduck.net/eo-library/pdfs/.
They are gitignored because 512 PDFs are too large for GitHub Pages.
Upload new files with the trd-memes-upload Worker (upload-memes.therubberduck.net), key prefix eo-library/pdfs/.
Local copies in this folder are for preview only.
If a file cannot be cached, the page falls back to the official Federal Register / govinfo pdf_url.
